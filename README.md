# Line-wise Text Summarizer

This is a Streamlit web app that summarizes **each line** of input text using Hugging Face Transformers.

## Features
- Uses `pipeline("summarization")` from Hugging Face.
- Handles multi-line input and summarizes each line separately.
- Outputs a clean table of line-wise summaries.
